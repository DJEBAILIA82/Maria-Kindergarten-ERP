# Maria Kindergarten ERP Design System

Version: 1.0

---

# Design Vision

Maria Kindergarten ERP is a professional management application.

The interface should inspire:

- Trust
- Simplicity
- Clarity
- Professionalism

Avoid decorative interfaces.

Every screen must focus on usability.
